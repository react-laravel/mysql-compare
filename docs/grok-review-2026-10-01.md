# Grok 报告核对与修正（2026-10-01）

报告指出的主要代码缺口成立，已在当前工作区修正。下面记录具体行为、核对结论和验证边界，方便复核。

## 连接与凭据

| 报告项 | 核对结果与处理 |
| --- | --- |
| MySQL / PostgreSQL / Redis 无 TLS | 已启用 TLS 库，新增“自动 / 校验证书与主机名 / 禁用”及可选私有 CA PEM。自动模式对非回环直连严格验证证书，不会回退明文；回环直连和 SSH 隧道默认使用各自传输。 |
| SSH 首次静默信任 | 认证之前产生指纹挑战；后端原生对话框展示主机、当前和旧指纹，只有实际确认才持久化。升级后的旧 TOFU 记录也必须逐主机确认一次。每个独立转发会话仍在认证和转发之前校验。转发时密钥变化会记录当前及预期指纹，查询错误优先提示关闭连接后重新核对并连接。 |
| 信任文件损坏被当成空表 | 损坏、丢失已保存记录或外部修改会锁定 SSH 使用，应用其他功能仍可打开；不会重新默默信任。设置 → 连接可查看或删除已保存指纹，删除同样需要原生确认，并关闭对应连接。 |
| `master.key` 与密文同目录 | 主密钥迁入 macOS Keychain / Windows Credential Manager / Linux Secret Service。旧明文及 v1 密文迁成 v2；持久化及 OS 存储读回成功之后才删除旧 `master.key`。新输入始终按明文加密，`enc:v1:` / `enc:v2:` 开头的真实密码不会被误当成密文。 |
| 存储权限、非原子写入 | Unix 数据目录 0700、凭据和信任文件 0600；权限失败返回错误。临时文件先安全创建、写入并同步，再改名替换，失败保留原文件。 |
| OS 凭据存储不可用 | 明确失败并保留原记录及迁移密钥，不回退本地明文密钥。解锁 OS 凭据存储后需重启完成迁移。 |

SSH 隧道保护到 SSH 服务器。其后的数据库连接按远端网络配置工作。当前库不能把数据库 TLS 的原服务器名称与本地隧道 TCP 端点独立配置，因此“SSH + 显式严格数据库 TLS”会明确拒绝，不能通过关闭证书验证伪装成功。

## 文件、SQL 与更新

| 报告项 | 核对结果与处理 |
| --- | --- |
| IPC 任意本地路径读写 | 导入、导出、SFTP 的路径由后端原生文件对话框选择，签发五分钟有效、用途与精确路径绑定、单次使用的授权。后端批量验证全部授权后才消费，使用核对后的规范路径；伪造本地路径不会被执行。拖放上传需通过原生文件选择确认。 |
| CSP 允许内联脚本和任意回环服务 | 生产 CSP 移除脚本 `unsafe-inline`，连接仅保留自身和 Tauri IPC。开发 HMR 单独使用限定 5173 端口的策略；Monaco 及 worker 本地打包。删除 HTML 中重复的宽松 CSP，由 Tauri 配置注入。 |
| 主窗口可执行全部应用命令 | 桌面数据库客户端需要 SQL、同步和 SSH 能力。这本身不是跨用户提权。已补上本地路径与指纹确认的后端边界，并收紧 CSP；这些措施不构成对已完全控制渲染进程的绝对隔离。 |
| 排序方向直接拼 SQL | MySQL / PostgreSQL 浏览与导出统一限定 ASC / DESC，列名必须来自实际元数据。 |
| WHERE 黑名单 | 输入保留为高级 SQL 表达式，允许合法子查询。增加识别字符串、引用标识符和括号的检查，拒绝注释、未闭合字面量、额外语句与顶层 UNION / ORDER / LIMIT 等子句。它仍不是结构化参数化筛选语言。 |
| mysqldump 环境密码与 PATH | 从固定 MySQL 安装位置解析可执行文件；用 0700 临时目录中的 0600 配置文件传凭据，清除 `MYSQL_PWD`，隔离用户 login 配置，并传递同等 TLS 校验策略。失败或取消停止子进程、清理临时文件，保留原导出。 |
| “SSH 远端 mysqldump” | 额外确认这个选项实际执行本地程序，已移除误导选项。SSH 连接可使用本地 mysqldump 经已验证的隧道导出。 |
| SQL 导入直接整串执行、用分号计数 | 正确识别引号、注释、PostgreSQL dollar quote 与 MySQL DELIMITER。前端显示脚本预览，执行前后端再显示原生确认和语句数；逐条在同一事务执行，失败回滚支持事务的语句。拒绝冲突的事务控制、COPY FROM STDIN 和与分句器不兼容的会话字面量模式，并给出处理提示；原生 MySQL/PostgreSQL 客户端仍可处理这些脚本。 |
| MySQL DDL 回滚 | MySQL DDL 会隐式提交，非事务表及存储过程也可能保留已执行变更，不能承诺任意脚本全部回滚；原生确认明确说明。[MySQL 官方事务说明](https://dev.mysql.com/doc/refman/8.4/en/implicit-commit.html)取消同步或导入也不会撤销之前已经提交的变更。 |
| 复制表失败留下空表 | INSERT 失败后删除这次创建的目标表；清理失败会同时报告原始和清理错误。 |
| SQL 历史落盘 | 改为本次应用会话内存，清除旧 SQL localStorage 历史。切换标签仍能保留本次历史。 |
| 更新公钥公开 | 公钥应随应用公开，更新地址与当前 Git remote 一致，仓库没有发现签名私钥。这不是已证实漏洞；私钥泄露是条件风险。本轮没有更换发布身份或更新地址。 |

## 浏览、取消与界面性能

- 不再每次翻页同步精确 `COUNT(*)`。`LIMIT + 1` 返回当前行与 `hasMore`，非精确时展示已加载下界，不伪造总页数。
- 默认有主键的顺序翻页使用键集游标，支持复合主键；已访问页面可沿缓存游标前后翻。自定义排序和随机跳到未访问页面仍可使用 OFFSET，深页显示耗时提示。
- 无主键时不再隐式按所有列排序。需要稳定顺序时，应选定合适排序列；无唯一键的数据不保证跨页快照稳定。
- 隐藏字段下推查询，请求可见字段及编辑、定位必需的主键；无主键且全部字段隐藏时保留一列作为行载体。复制 JSON / INSERT 仅包含可见字段，编辑只修改实际加载的字段。选中行导出不会把缺失隐藏字段补成 NULL。
- SQL、解释计划、翻页、比较、同步、导入和导出接入操作 ID 与后端取消。独立控制连接执行 MySQL `KILL QUERY` / PostgreSQL `pg_cancel_backend`，避免取消排在已占满的五连接池后面。未完成的连接不会被归还继续使用，批处理循环及磁盘分区比较检查取消信号。
- SSH 建连也在阻塞工作线程运行，TCP/握手限制为 15 秒，认证前检查取消信号。可取消查询、SQL 导入和同步的单条语句限制为 60 秒，建连 / 池获取限制为 15 秒。取消停止后续操作，之前提交的写入保留。
- Redis 库展开改为单批 SCAN，支持继续扫描及服务端 MATCH。筛选不会因键在原先的一万个之后就认定不存在；空批次且游标未结束时继续提示扫描。达到显示上限可缩小搜索，结果去重并保留完整批次。
- SQL 结果、数据表、侧栏和 SFTP 文件列表窗口化，长值预览限制高度；完整 SQL 单元格按需打开。保留键盘导航、跨窗口焦点、全页选择及滚动定位。
- 后台 SQL 标签卸载 Monaco，保留草稿与视图状态；结果和标签状态仍保留以支持切回。
- SFTP 在阻塞工作线程运行。编辑器最多读取 8 MiB，导入最多 64 MiB；上传下载流式处理并先写临时文件。目录展示最多 20,000 项且明确提示截断，递归下载有深度与条目上限，拒绝本地符号链接穿越与不安全路径组件。
- MySQL REPAIR TABLE / OPTIMIZE TABLE 在被强制取消时可能损坏 MyISAM 表，因此后端拒绝在本应用可取消执行器中运行，并提示使用原生数据库客户端。[MySQL 官方 KILL 说明](https://dev.mysql.com/doc/refman/8.4/en/kill.html)
- Unix 终端改为等待 socket 就绪，减少空闲轮询；跨读取块的 UTF-8 字符保持完整，结束的会话从管理器清理。
- schema 缓存达到容量时逐项淘汰。连接、证书、认证、指纹和导入错误增加可执行的下一步提示，原始驱动信息仍保留供排查。

## 验证与边界

本轮使用独立临时 MySQL / PostgreSQL / Redis 服务，不连接或更改用户的真实数据库与凭据目录。

- 前端 438 项全量测试通过；TypeScript 检查和生产 UI 构建通过。
- Rust 102 项通过、0 失败；10 项需临时服务的测试由下述集成脚本单独通过。6 项真实 OpenSSH 回归确认：首次未知指纹确认前没有认证或转发；确认后成功，后续独立连接密钥变化被拒绝。
- 10 项真实数据库契约：账号与数据库 scope、PostgreSQL 多 schema、复合主键游标、隐藏大 TEXT / BLOB / JSON 不返回、事务失败回滚、非法排序和游标拒绝、取消及时返回且服务器上的慢查询停止、Redis 单批扫描及一万个之外的匹配。
- 真实 OpenSSH SFTP 回归：10 MiB + 123 字节上传/下载 SHA-256 一致；超限文件拒绝编辑；同名上传不会覆盖；0755 文件原子编辑后权限及所有权保持；服务器禁用 POSIX rename 时原文件与权限保留，临时文件清理。原子编辑使用 OpenSSH `posix-rename@openssh.com`，服务端没有该扩展或无法保持原权限时会明确拒绝编辑。
- 本机临时 CA 测试 MySQL / PostgreSQL 和 Redis TLS：受信任 CA 与正确主机名成功；不受信任证书和错误主机名失败。
- 实际浏览器中 10,000 行长 JSON 仅挂载 30 行，28px 行高，滚动到末行没有错位。Redis 新扫描 UI 使用 React DOM 交互测试；后续浏览器工具不可用，该部分没有浏览器运行证明。

OS 凭据接口已经编译、迁移失败与竞争场景使用可注入 provider 验证；未为了测试访问用户 Keychain。未实测 Windows / Linux OS 凭据服务，也未启动打包后的原生 WebView验证 CSP。CI 配置已同步依赖与 Redis 服务，但远端 CI 未运行；默认 Docker 契约服务不提供本轮私有 CA，TLS 子场景需要运行本机临时证书脚本，不能把 CI 的普通连接测试当成 TLS 证明。
